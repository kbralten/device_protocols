# Device Protocols

This repository is a collection of protocol information for electronics test equipment (for example: oscilloscopes, multimeters, signal generators, power supplies, and related devices). The material here has been gathered from multiple sources — including reverse engineering, service and user manuals, forum posts, and other public or private documents — and is intended to document commands, pinouts, communication formats, and examples to help engineers and researchers interface with these devices.

Purpose
- Provide a searchable and shareable reference of device protocols and command sets.
- Capture examples and implementation notes for interfacing with test equipment.

Contents
- Markdown files containing protocol notes and extracted command references (for example: `borui.md`, `rd6xxx.md`, `sk120x.md`).
